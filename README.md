# Reverb-Clone-FSW

An application that's a clone of the website reverb.com, with the goal of gaining a deeper understanding of
full-stack web development.

## Technologies/Languages
- Java
- Javascript
- Vite-React
- HTML
- CSS
- Springboot
- Springboot-Security
- PGAdmin
- Postgessql
- Netlify
